Resources for Web Programming Course

Resources for browser-side programming include both books and web resources. HTML – Hypertext Markup Language – is used to define portable documents.
These can be properly displayed on any operating system, in any browser (including text-based and mobile ones).
Documents require a web browser to be displayed to the user.

XHTML is a version of HTML that follows XML syntax. It uses many of the same elements as HTML, but it requires stricter markup. For example, elements must be properly closed and nested.

HTML gives a webpage its structure. Headings organize the content, paragraphs group related ideas, and links connect readers to other pages or to sections within the same page.

CSS controls how that content appears. You can use it to set spacing, align elements, and adapt a layout to different screen sizes. A floated image is one way to let text wrap around a visual.

Browser developer tools let you inspect the HTML and try CSS changes as you work. Try changing the image width or its margins and watch how the surrounding text rearranges itself.
